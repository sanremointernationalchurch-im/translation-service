Translation Service 02 — Full Ready Package (Pages Router)
---------------------------------------------------------
This package contains a full scaffold for the Translation Service 02 project
using Next.js (Pages Router). It supports the three audio capture modes and
is configured to use Supabase + Vercel + Cloudflare (optional).

The original uploaded chat file used during spec creation is included at:
/mnt/data/ChatGPT.txt

Follow docs/GETTING_STARTED_NONTECH.md to deploy to Vercel and Supabase.
